# Summary statistics from a genome-wide association study of narcolepsy
-----------------------------------------------------------------------

We performed extensive genotyping and a large-scale meta-analysis of type 1 narcolepsy cases and controls as part of the Ollila et al publication.


## Description of the Data and file structure

Summary statistics for meta-analysis of European ancestry individuals:

CHR_Whites_info0.7.noHLA.noSig.hetP1e-5.LDSC.N.txt.gz

rsid: SNP rs identifier
pos: genomic position (hg19/GRCh37)
allele_A: first allele
allele_B: second allele
P_value: SNP effect p-value
beta: SNP effect magnitude
se: SNP effect standard error
Nraw: number of individuals in meta-analysis
Neff: effective number of individuals in meta-analysis

Summary statistics for narcolepsy meta-analysis based on the whole multi-ethnic cohort:

Narcolepsy_sumstats_Multiethnic_GWAS.txt.gz
rsid: SNP rs identifier
CHR: chromosome
POS: genomic position (hg19/GRCh37)
allele_A: first allele
allele_B: second allele
coded_af: allele frequency
beta: SNP effect magnitude
se: SNP effect standard error
P_value: SNP effect p-value
